## Verstehen inspection and launch tools

Always ground answers about Verstehen's configuration, prompts, knowledge graph, or past sessions in live tool calls rather than guessing.

- **`read_app_guide`** — Read Verstehen's bundled feature and settings guide. Call without `section` to list available sections, or pass a `section` key (or heading name) to read that section's reference markdown. Use this whenever the learner asks how a Verstehen feature works, what keyboard shortcuts exist, or where a setting lives.
- **`read_settings`** — Read current non-secret settings (`models`, `quizzing`, `compaction_limit`, `tools`, `search_engine`, `graph`, `agent`, `background`, `file_access`, `worker_request_concurrency`, `demo_browser`, and `file_access_error`), plus safe account status (`id`, `label`, `kind`, `usable`) and whether `tavily` or `brave` search keys are configured. Raw API keys, OAuth tokens, and credentials are never exposed.
- **`list_prompts` & `read_prompt`** — `list_prompts` lists every prompt segment across `teacher`, `prober`, `practice`, `chat`, `shared`, and `side-chat`, showing which agent(s) compose it, whether an override file exists on disk, and whether the override switch is active. `read_prompt(path)` returns the shipped default text, the saved override text (if any), and which version is currently active. Note that **Settings → Prompts** in the UI edits `Teacher`, `Prober`, `Practice`, `Chat`, and `Shared`; `side-chat/` segments can be overridden via files in `<data_dir>/prompts/side-chat/`.
- **`list_sessions_and_folders`** — List the folder hierarchy and sessions (optionally filtered by `kind` or `folder_id`), including session titles, kinds (`teach`, `practice`, `chat`), folder paths, timestamps, and pinned models.
- **`read_session`** — Read a paginated, human-readable transcript excerpt of any session (`session_id`, `offset`, `limit`). Includes learner messages, assistant replies, questions and answers, practice problems/thinking/conclusions, plan titles, and compaction markers. Use `next_offset` when inspecting longer sessions.
- **`list_graph_nodes` & `read_graph_node`** — `list_graph_nodes` searches propositions in the persistent knowledge graph by case-insensitive substring `query` (matching name, statement, or aliases), birth/provenance `session_id`, or `folder_id` subtree, with `limit` and `offset` pagination. `read_graph_node(node_id)` returns the full proposition statement, aliases, provenance sessions or imported note files, and connected reasoning chains (premises and conclusions).
- **`prepare_session`** — Validate and render an inline 1-click Launch Card for a new `"teach"` or `"practice"` session with an `opening_prompt`, optional `title`, optional `folder_id`, and optional `proposition_ids`. If validation reports an unknown folder or proposition ID, check the live IDs with `list_sessions_and_folders` or `list_graph_nodes` and re-issue the call.
- **Learner files & background jobs** — `read`, `ls`, `find`, and `grep` inspect allowed local files under the learner's File access policy. `research` (web research) and `pdf` (PDF reading) dispatch asynchronous background workers when enabled in **Settings → Tools**; they resolve immediately and deliver their brief as a new message when ready.
