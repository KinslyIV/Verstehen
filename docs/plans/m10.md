# M10 — Practice sessions

> Status: **approved by the user (2026-11-22).** LearnHarness specification commit: `cb25c8e` in
> `/home/immata/learnharness` (`git -C /home/immata/learnharness show cb25c8e:<path>`).

## Overview

Add **practice sessions** (`kind = "practice"`) as a second lesson mode alongside teaching sessions.
A practice session skips probing, planning, extraction, and graph mastery writes, and runs a
dedicated **practitioner** agent (`teaching/prompts/practice/` + allowlisted `shared/` voice,
accuracy, mental-model, side-conversation, and formatting rules) with `problem` and `conclude`
tools, read-only learner file tools, background `research` and `pdf` tools, and optional read-only
graph lookup (`list_sessions`, `list_propositions`).

- **What changes:**
  - SQLite widens `sessions.kind` to `('teach', 'practice')` via FK-safe migration `0010`, and
    sync payloads (`store/sync.py`) accept both kinds.
  - Backend adds `teaching/practice/` (problem/conclude schemas, weak-model argument healing,
    whole-graph target ID resolution, turn-scoped `PracticeGate`, derived state folds, practitioner
    agent builder), turn/projection/continuation/dismissal handling in `session/`, `pending_problem` /
    `pending_question` flags on `GET /api/sessions`, extraction refusal for practice sessions, open-problem
    model-solution redaction in `sidechat/`, and practice session import in `lh_import/`.
  - Frontend adds `app/src/lib/practice/` (`PracticeDock`, `ProblemCard`, `ThinkingCard`,
    `ConcludeCard` with verbatim `Model solution` reveal + `Metadata` popover), `GraphContextCard`
    for picked-node threads, `Next problem →` composer morphing, Esc problem dismissal, sidebar
    `+ Teaching` / `Practice` creation and `Teaching | Practice | All` filter, practice-clean
    context menu / delete dialog, knowledge summary practice count, and Chains table exclusion.
- **What the user notices:**
  - Starting practice sessions from the sidebar (`Practice`), `/session/new` (`Teach | Practice`
    toggle preserving draft and picks), or `/graph` (`Start teaching` / `Start practice` on picks).
  - Active problems dock `YOUR THINKING` above the footer with Esc discard; concluding reveals the
    committed solution + verdict + metadata and morphs the composer into `Next problem →`.
  - Sidebars show `Problem waiting` / `Waiting for input`, a right-aligned dumbbell icon, and a
    `Teaching | Practice | All` filter; `/graph` shows a practice session count without indexing
    practice sessions into the Chains table or running graph extraction on them.
- **Non-obvious effects:**
  - Migration `0010` rebuilds `sessions` while child tables (`entries`, `jobs`, `artifact_views`,
    `side_threads`) reference `sessions(id) ON DELETE CASCADE` and `0006` defined trigger
    `delete_session_usage` on `sessions`. `PRAGMA foreign_keys=OFF` must run outside `BEGIN;`,
    followed by `PRAGMA foreign_key_check`, recreating `delete_session_usage`, committing, and
    re-enabling `PRAGMA foreign_keys=ON`.
  - Reloading an open posed problem must NOT trigger a phantom `continue` turn (`needs_continuation`
    must ignore clean `problem` acks in both backend and frontend).
  - Side-chat helper prompts must keep `modelSolution` hidden for an open problem even across
    compaction boundaries.

## User decisions

All five design questions were decided by the user on 2026-11-22:

1. **Starting a practice session:** Sidebar header has `+ Teaching` (`/session/new`) and
   `Practice` (`/session/new?mode=practice`); `/session/new` provides a `Teach | Practice` mode
   toggle preserving draft text and picked graph nodes; `/graph` offers both `Start teaching` and
   `Start practice` buttons when nodes are picked.
2. **Sidebar, context menu, and Delete dialog:** Port LearnHarness's `Teaching | Practice | All`
   filter above the session list (default `All`, persisted in `localStorage`), right-aligned muted
   dumbbell icon on practice rows, and `Problem waiting · <time>` / `Waiting for input · <time>`
   status (`pending_problem` and `pending_question` on `GET /api/sessions`). Hide `CoverageMenuBlock`
   from practice session context menus and hide the *"Also remove its graph traces"* option /
   extraction copy in `DeleteSessionDialog` for practice sessions (sending `mode=preserve-graph`).
3. **`GraphContextCard` in thread:** Add LearnHarness's collapsible `GraphContextCard` (`Graph
   context · N propositions · M chains`, collapsed by default) in `session-thread.svelte` for both
   teaching and practice sessions started with picked graph nodes.
4. **Practitioner `research` and `pdf` tools vs Settings → Tools:** Faithful to LearnHarness
   `cb25c8e`: practice always arms `research` and `pdf` regardless of Settings → Tools switches
   (still respecting background consent and File access). `list_sessions` and `list_propositions`
   still follow `graph.enabled && agent.graph_tools`. No `send_to_user`, `demo`, `visual`,
   `show_image`, plan, or question tools.
5. **LearnHarness import (`import-learnharness`):** Extend `verstehen.lh_import` in M10 to import
   `kind == "practice"` sessions as well (remapping practice marker/conclude details and usage role
   `"practice"`).

## Tasks

### Backend — T1 (Migration, sync & practitioner domain)

1. **FK-safe table rebuild migration (`store/database.py`, `store/migrate.py`, `store/migrations/0010_practice_sessions.sql`):**
   - Add `foreign_keys: bool = True` to `Database.transaction(...)`. When `foreign_keys=False`,
     execute `PRAGMA foreign_keys=OFF` under `self._lock` before `BEGIN`, run `PRAGMA
     foreign_key_check` before commit (raising `RuntimeError` if non-empty), and always restore
     `PRAGMA foreign_keys=ON` in `finally:` after commit/rollback.
   - Support leading `-- foreign_keys: off` in `store/migrate.py`.
   - Create `0010_practice_sessions.sql` rebuilding `sessions` with
     `kind TEXT NOT NULL CHECK (kind IN ('teach', 'practice'))` and recreating trigger
     `delete_session_usage`. Run `make lock-migrations`.
2. **Session store & Sync (`store/sessions.py`, `store/sync.py`):**
   - `Session.kind: Literal["teach", "practice"] = "teach"` and `SessionsStore.create(..., kind="teach")`.
   - `_SessionUpsertPayload.kind: Literal["teach", "practice"] = "teach"` in `store/sync.py`.
3. **Practice prompt composition (`teaching/prompts.py`):**
   - Accept `kind: Literal["prober", "teacher", "practice"] = "teacher"`.
   - For `"practice"`: omit `system-prompt.md`, compose sorted `practice/*.md` fragments plus the
     exact allowlist `PRACTICE_SHARED_FRAGMENTS = ("10-voice.md", "15-accuracy.md",
     "16-mental-model.md", "35-side-conversations.md", "40-formatting.md")` (`cb25c8e:src/agent/prompt-segments.ts`),
     honoring `agent.prompts` overrides via `fragment_text`.
4. **Practitioner package (`backend/src/verstehen/teaching/practice/`):**
   - Port from `cb25c8e:src/core/practice-problems.ts`, `src/agent/tools/practice.ts`,
     `src/core/contracts/chat.ts`, `src/core/native-messages.ts`, `src/agent/tool-execute.ts`:
     - `schemas.py`: `ProblemMode`, `ConcludeOutcome`, `Rung`, `MissClass`, `ProblemInput`,
       `ConcludeInput`, `ActiveProblem`, `PRACTICE_PROBLEM_TOOL`, `PRACTICE_CONCLUDE_TOOL`,
       `THINKING_LABEL`, `PROBLEM_ACK_TEXT`, `CONCLUDE_ACK_TEXT`, `NEXT_PROBLEM_TEXT`.
     - `healing.py`: weak-model argument healing (`heal_encoded_arguments`: quoted enums,
       `"null"`, `"true"`/`"false"`, JSON-stringified arrays, empty `target: []` omitted) and
       `strip_model_value_debris` + `resolve_target_id` (exact `id` then case-insensitive trimmed
       `name` match against all graph nodes read fresh per pose).
     - `state.py`: `active_problem_of`, `pending_problem_dismissal_of`,
       `problem_input_for_conclude`, `model_solution_for_conclude`,
       `concluded_by_dismissal_pair`, `has_problem_pose`.
     - `tools.py`: `PracticeGate` (seeded from `active_problem_of`, allows mid-turn
       `conclude` → `problem`), `problem` tool (canonicalizes `target` IDs on the saved
       `ToolCallPart.arguments`, rejects unknown targets via `ModelRetry` without arming gate,
       persists clean `PROBLEM_ACK_TEXT` `ToolResultEntry`, ends turn safely across mixed batches),
       `conclude` tool (requires active gate, frees gate, returns `CONCLUDE_ACK_TEXT`, lets turn
       continue for closing prose), and `build_practitioner`.

### Backend — T2 (Turns, API, side chat, graph gates & `lh_import`)

1. **Roles & compaction (`providers/resolve.py`, `session/compactions.py`):**
   - Map `"practice": "strong"` in `ROLE_SLOT`; widen `TurnRole = Literal["teacher", "prober", "practice"]`.
2. **Turns, projection & continuation (`session/turns.py`, `session/projection.py`, `session/cause.py`, `teaching/questions/pending.py`):**
   - `needs_continuation(entries)` returns `False` when trailing tool results include a clean
     `problem` ack (`cb25c8e:src/core/input-events.ts`).
   - `projection.py` renders `practice-thinking` (`**Your thinking:**\n<text>` / LH `THINKING_LABEL`
     format per `cb25c8e:src/core/native-messages.ts`) and `practice-next` (`NEXT_PROBLEM_TEXT`) as
     learner messages; skips `problem-dismissed`.
   - `cause.py` skips synthetic `conclude(outcome="dismissed")` assistant entries
     (`provider == "synthetic" and model == "synthetic-conclude"`).
   - `turns.py`: add `thinking` and `next` to `TurnInput`, extend dismissal for `dismiss-problem`
     (`problem_call_id` — appends `problem-dismissed` marker without starting a turn, and parks
     on a running turn like question dismissals per `cb25c8e:app/api/chats/[id]/dismiss/route.ts` and
     `dismissal-park.ts`), inject `concluded_by_dismissal_pair` when
     `pending_problem_dismissal_of` is set on `text`/`continue`/`thinking`/`next`, wire practice agent
     (always arming `research` + `pdf` jobs when consented, ignoring Settings → Tools toggles, plus
     `prober_graph_tools` when `graph.enabled && agent.graph_tools`, and learner-file tools), stream
     & persist clean `problem` ack + canonicalized target IDs and end turn cleanly, and skip
     extraction in `settle` for practice sessions.
3. **API & extraction refusal (`api/sessions.py`, `session/sessions.py`, `graph/extraction_service.py`):**
   - `POST /api/sessions` accepts `kind: Literal["teach", "practice"] = "teach"`.
   - `GET /api/sessions` adds `kind`, `pending_question`, `pending_problem`.
   - `SessionService.get` returns `coverage=None` for practice sessions.
   - `ExtractionService.start` refuses practice sessions with `400`.
4. **Side chat (`sidechat/segments.py`, `sidechat/lesson.py`):**
   - Segment boundaries include `practice-thinking` and `practice-next`; `problem` tool calls count as
     visible segment entry points (`cb25c8e:src/core/side-chat.ts`).
   - Lesson markdown hides `modelSolution` for an open problem (`### OPEN problem — the learner is
     working on it now (its solution is hidden from you)`), even when posed before compaction, and
     renders past problems, thinking traces, and conclusions with revealed `> **Model solution**`
     or dismissal line (`cb25c8e:src/core/session-markdown.ts`).
5. **LearnHarness import (`backend/src/verstehen/lh_import/`):**
   - Import `kind == "practice"` chats, remap `practice-thinking`, `problem-dismissed`,
     `practice-next`, and `conclude` details (`problemCallId` → `problem_call_id`, drop legacy
     `commit`, warn/drop `images` if present), skip `check_plan` on practice chats, assign `"practice"`
     usage role (`cb25c8e` compatibility). Regenerate `make api-types`.
