# Decisions

What has been decided, grouped by area. **The user's decisions are the authority**; code can be
rewritten freely, a user decision is changed only by the user. A new decision **replaces** the one
it contradicts, in place, in the same commit; code that no longer matches is changed or listed in
the [roadmap](roadmap.md). Orchestrator decisions made during implementation wait in the review
queue below until the user reviews them at the end of the milestone.

Each row keeps its original wording and date. Spike write-ups are in [spikes](spikes/).
