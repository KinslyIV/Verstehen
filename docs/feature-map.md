# Feature map

Every feature, how to reach it, and how to verify it, grouped by the same areas as the
[architecture](architecture.md). A new or changed feature updates its row in the same commit.
`make check` fails when a flow file under `app/verify/<area>/` or `app/verify-live/` is missing from
a **Verify flow** column, or when that column names a flow with no file (`tools/check_feature_map.py`).
Flow names are the file names without `.flow.ts`; flows run in the default dark theme.
Only `shell-layout` and `settings` explicitly test a theme. Locally,
Playwright uses 1 worker on machines with ≤4 CPU threads and at most 3 elsewhere; CI uses its default.
How to run flows and keep evidence is in the verify skill (`.claude/skills/verify/SKILL.md`).
